TransitOps : Fleet Operations Platform

Role-based fleet operations platform for vehicle, driver, trip dispatch, maintenance, compliance and financial management with built-in dispatch safety rules

Hover Over the image to see image description

  • Built a full-stack, multi-tenant fleet platform with five role-based workspaces (Organization Admin, Fleet Manager, Driver, Safety Officer and Financial Analyst), secured with JWT authentication and role-restricted API actions.
  • Enforced dispatch guardrails: suspended drivers and vehicles under maintenance are excluded, and licence validity and cargo capacity are validated before a trip can be dispatched.
  • Automated compliance with a scheduled node-cron job that suspends drivers with expired licences and emails reminders for upcoming expiries, while Socket.IO pushes live trip and status updates to connected users.
  • Implemented organization onboarding: email verification, Razorpay checkout with server-side payment verification, then an automated activation link and PDF receipt by email.
  • Delivered financial reporting on operating cost, cost per kilometre, revenue and fleet ROI with CSV and PDF exports, backed by PostgreSQL with Prisma, Swagger API docs, GitHub Actions CI and Render deployment.
